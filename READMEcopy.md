
# AI-Powered DevOps Monitoring

## Project Overview
An AI-based monitoring solution designed to detect unusual server activities and improve cloud infrastructure reliability.

## Technologies Used
- Python
- Machine Learning
- Scikit-learn
- NumPy
- AWS
- Docker
- Linux

## Features
- AI-based anomaly detection
- Server performance monitoring
- Identification of unusual activities
- Automated monitoring alerts

## Installation

Install dependencies:

pip install -r requirements.txt

## Run Project

python app.py

## Objective
To demonstrate how AI and DevOps automation can improve infrastructure monitoring and troubleshooting.
